# Brand and visual assets

**Primary tagline: From yard to site.**

Supporting lines used in the application: **Big plans. Better deliveries.** / **Less chasing. More building.** / **Every handoff matters.**

The original mark combines a building outline with an amber receiving check. Its rounded navy square reads clearly as an app icon; the house shape refers to the project site, while the check represents an accountable handoff. The colour system uses soft dark navy #073B5C, clear blue #087BB5, construction amber #FFB638 and pale blue-grey surfaces. It does not use Barclays, Yango or supplier logos.

The hero is an original AI-generated illustration of fictional African construction and delivery workers, created for this prototype. It does not depict actual staff, a real branch or actual product packaging. The logo, vehicle marker and fifteen product/category illustrations were authored for this project. Original SVG artwork is dedicated under CC0-1.0 to the extent the project author holds rights. The generated hero is also offered for reuse with the project to the extent rights exist; no third-party stock licence or paid-photo purchase is required. Trademark and real-person rights are not purported to be licensed by this notice.
